# Kelvin's Portfolio

A responsive personal portfolio for Kelvin Takudzwa Mtizwa, built with semantic HTML, CSS, and a tiny JavaScript enhancement. Designed as a lightweight static site for easy deployment on Vercel.

## Run locally
Open `index.html` in your browser.

## Deploy
Connect this repository to Vercel as a static site. No build command or dependencies are required.

## Personalize
Update the copy in `index.html` as your skills, projects, and contact details grow. The current version intentionally links to public GitHub projects and does not publish an email address until one is provided.
